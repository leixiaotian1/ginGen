description: 分析改动并生成/执行 Git 提交
---

目标：帮我完成一次高质量的 Git 提交。

请按以下顺序执行：

1) 检查当前状态
- 运行 `git status`
- 运行 `git diff` 和 `git diff --staged`
- 运行 `git log -5 --oneline`，参考本仓库提交风格

2) 总结改动并给出提交信息建议
- 用 1-2 句话说明这次改动的目的
- 产出一个简洁提交标题（建议遵循 Conventional Commits，如 `feat: ...` / `fix: ...` / `chore: ...`）

3) 若我在本次对话中明确确认“执行提交”
- 仅添加与当前任务相关的文件
- 执行提交
- 再次运行 `git status` 验证结果

约束：
- 未经我确认，不要直接提交
- 不要推送远程
- 不要使用破坏性 git 命令
